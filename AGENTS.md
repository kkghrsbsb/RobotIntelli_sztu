# Research Documentation Flow

Use this workflow for project research, source collection, evidence capture, synthesis, or resuming an existing research thread. Read [.agents/research-flow/protocol.md](.agents/research-flow/protocol.md), then load only the relevant skill:

| Need | Skill |
| --- | --- |
| Establish a research question and map existing material | [research-orient](.agents/skills/research-orient/SKILL.md) |
| Turn a source into traceable evidence | [research-capture](.agents/skills/research-capture/SKILL.md) |
| Compare evidence and draft a bounded conclusion | [research-synthesize](.agents/skills/research-synthesize/SKILL.md) |
| Continue after a pause or context change | [research-resume](.agents/skills/research-resume/SKILL.md) |
| Verify and document access to a research tool | [research-tool-connect](.agents/skills/research-tool-connect/SKILL.md) |

Treat source claims, analysis, and user decisions as distinct. At the start of a topic, learn what the researcher can explain; when they express confusion, clarify the missing link then and there. Only their actual restatement and stated confidence describe their understanding. The main research conversation maintains `.agents/research-flow/understanding.md`; manually opened conversations return evidence. Actual sources and artifacts outrank saved summaries. Linear owns action items.

Use [.agents/research-flow/tools/](.agents/research-flow/tools/README.md) for checked connection procedures. Recheck availability in the current environment before relying on a prior note.

## 本仓库的学习方式

这是一份强化学习入门资料。用户主要在观看视频时提出具体疑问；先解释当下卡住的概念、公式或实验，再按需定位到本仓库的讲义页码、Notebook 单元和原书章节。不要把每次答疑变成进度考核或完整研究流程。

只在形成阶段性认识、纠正关键误解、或用户明确复述自己的理解时，简要更新 `understanding.md`。未由用户说出的理解和把握一律记为未确认。视频分 P、课程讲次、原书章节可能不完全同号，引用时分别标明。
